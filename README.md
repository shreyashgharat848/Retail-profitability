# Management Consulting Projects

Two case-style projects built to demonstrate structured problem solving, quantitative analysis and recommendation skills.

| # | Project | Type | Tools |
|---|---------|------|-------|
| 1 | [D2C Brand: Market Entry into Tier-2/3 India](project1-d2c-market-entry/) | Growth strategy | Python, Excel, PowerPoint |
| 2 | [Regional Supermarket: Profitability Improvement](project2-retail-profitability/) | Cost / operations | Python, Excel, PowerPoint |

> **Note:** Clients ("GlowRoot", "FreshBasket") are hypothetical. Data is simulated or calibrated on public benchmarks, as stated in each project.

python -m venv venv
